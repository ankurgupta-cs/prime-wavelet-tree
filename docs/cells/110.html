Cell 110: PWT over dmin, byte-aligned

A prime wavelet tree over the primes of dmin(n) for every Carmichael number n, with one byte-aligned VByte code per symbol. Decoding rebuilds each n from its path. The remaining primes of n come from factoring the cofactor r⋆.

Build

This file is not hosted. Rebuild it from the oracle with:

make fetch-oracle rebuild-110

The target first builds the dmin paths (see intermediate files), then runs the encoder:

trie_paths data/carmichael-1e24-oracle.orc1 work/dpaths.bin --fields 12 --threads N
pwt2_encode work/dpaths.bin data/carmichael-1e24-oracle.orc1 work/c110-pwt-dmin-bytes.pwt2n --fields 12 --naive --scratch work/scratch --chunk 33554432 --threads 4

Verify, decode and certify

make verify-110
make fetch-oracle certify-110

Verify first checks the size and SHA-256 of the file. Then the targets run these commands:

# make verify-110
pwt2_decode work/c110-pwt-dmin-bytes.pwt2n
# make certify-110
pwt2_decode work/c110-pwt-dmin-bytes.pwt2n --certify data/carmichael-1e24-oracle.orc1
# make decode-110
pwt2_decode work/c110-pwt-dmin-bytes.pwt2n --emit-n work/c110.n.raw
# make paths-110
pwt2_decode work/c110-pwt-dmin-bytes.pwt2n --emit-paths work/c110.paths.bin --fields 12

N is the number of threads. The reproduce page explains the folders and the defaults.
