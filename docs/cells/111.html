Cell 111: PWT over dmin, coded

A prime wavelet tree over the primes of dmin(n) for every Carmichael number n, coded by rANS with context models. Decoding rebuilds each n from its path. The remaining primes of n come from factoring the cofactor r⋆.

Build

Rebuild the file from the oracle with:

make fetch-oracle rebuild-111

The target first builds the dmin paths (see intermediate files), then runs the encoder:

trie_paths data/carmichael-1e24-oracle.orc1 work/dpaths.bin --fields 12 --threads N
pwt2_encode work/dpaths.bin data/carmichael-1e24-oracle.orc1 work/carmichael-1e24-cell111-pwt-dmin.pwt2 --fields 12 --ctx-set 3 --scratch work/scratch --chunk 33554432 --threads 4

Verify, decode and certify

make fetch-111 verify-111
make fetch-oracle certify-111

Verify first checks the size and SHA-256 of the file. Then the targets run these commands:

# make verify-111
pwt2_decode data/carmichael-1e24-cell111-pwt-dmin.pwt2
# make certify-111
pwt2_decode data/carmichael-1e24-cell111-pwt-dmin.pwt2 --certify data/carmichael-1e24-oracle.orc1
# make decode-111
pwt2_decode data/carmichael-1e24-cell111-pwt-dmin.pwt2 --emit-n work/c111.n.raw
# make paths-111
pwt2_decode data/carmichael-1e24-cell111-pwt-dmin.pwt2 --emit-paths work/c111.paths.bin --fields 12

N is the number of threads. The reproduce page explains the folders and the defaults.
