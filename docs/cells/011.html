Cell 011: PWT over all primes, coded

A prime wavelet tree over the full prime factorization of every Carmichael number n, coded by rANS with context models. Every prime of every n is on its path, so no factoring is needed.

Build

Rebuild the file from the oracle with:

make fetch-oracle rebuild-011

The target first builds the full factorizations (see intermediate files), then runs the encoder:

trie_paths data/carmichael-1e24-oracle.orc1 work/fpaths.bin --full --fields 14 --threads N
pwt2_encode work/fpaths.bin data/carmichael-1e24-oracle.orc1 work/carmichael-1e24-cell011-pwt-full.pwt2 --fields 14 --full --ctx-set 3 --scratch work/scratch --chunk 33554432 --threads 4

Verify, decode and certify

make fetch-011 verify-011
make fetch-oracle certify-011

Verify first checks the size and SHA-256 of the file. Then the targets run these commands:

# make verify-011
pwt2_decode data/carmichael-1e24-cell011-pwt-full.pwt2
# make certify-011
pwt2_decode data/carmichael-1e24-cell011-pwt-full.pwt2 --certify data/carmichael-1e24-oracle.orc1
# make decode-011
pwt2_decode data/carmichael-1e24-cell011-pwt-full.pwt2 --emit-n work/c011.n.raw
# make paths-011
pwt2_decode data/carmichael-1e24-cell011-pwt-full.pwt2 --emit-paths work/c011.paths.bin --fields 14

N is the number of threads. The reproduce page explains the folders and the defaults.
