Cell 010: PWT over all primes, byte-aligned

A prime wavelet tree over the full prime factorization of every Carmichael number n, with one byte-aligned VByte code per symbol. Every prime of every n is on its path, so no factoring is needed.

Build

This file is not hosted. Rebuild it from the oracle with:

make fetch-oracle rebuild-010

The target first builds the full factorizations (see intermediate files), then runs the encoder:

trie_paths data/carmichael-1e24-oracle.orc1 work/fpaths.bin --full --fields 14 --threads N
pwt2_encode work/fpaths.bin data/carmichael-1e24-oracle.orc1 work/c010-pwt-full-bytes.pwt2n --fields 14 --full --naive --scratch work/scratch --chunk 33554432 --threads 4

Verify, decode and certify

make verify-010
make fetch-oracle certify-010

Verify first checks the size and SHA-256 of the file. Then the targets run these commands:

# make verify-010
pwt2_decode work/c010-pwt-full-bytes.pwt2n
# make certify-010
pwt2_decode work/c010-pwt-full-bytes.pwt2n --certify data/carmichael-1e24-oracle.orc1
# make decode-010
pwt2_decode work/c010-pwt-full-bytes.pwt2n --emit-n work/c010.n.raw
# make paths-010
pwt2_decode work/c010-pwt-full-bytes.pwt2n --emit-paths work/c010.paths.bin --fields 14

N is the number of threads. The reproduce page explains the folders and the defaults.
