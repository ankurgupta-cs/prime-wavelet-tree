Cell 111x: PWT over d∗, coded

The tree of cell 111 over a different stopping divisor d∗(n) of each Carmichael number n. A heuristic search chooses d∗(n) to make the tree smaller, and it keeps dmin(n) for most numbers. Decoding works as for cell 111. The file stores the chosen divisors, so it can be rebuilt without repeating the search.

Switches: A on, B on, C on. What the switches mean.

Build

The file stores the chosen divisors, so it can be rebuilt without repeating the search. Rebuild it from the hosted file with:

make fetch-111x fetch-oracle rebuild-111x

The target exports the stored paths and encodes them again:

pwt2_decode data/carmichael-1e24-cell111x-pwt-dstar.pwt2 --emit-paths work/c111x.paths.bin --fields 14
pwt2_encode work/c111x.paths.bin data/carmichael-1e24-oracle.orc1 work/carmichael-1e24-cell111x-pwt-dstar.pwt2 --fields 14 --ctx-set 3 --scratch work/scratch --chunk 33554432 --threads 4

Two other routes exist. The search route reruns the divisor search (see the reproduce page). The masks route encodes the file from the masks that the search writes (format). The masks of the published search are not hosted.

Verify, decode and certify

make fetch-111x verify-111x
make fetch-oracle certify-111x

Verify first checks the size and SHA-256 of the file. Then the targets run these commands:

# make verify-111x
pwt2_decode data/carmichael-1e24-cell111x-pwt-dstar.pwt2
# make certify-111x
pwt2_decode data/carmichael-1e24-cell111x-pwt-dstar.pwt2 --certify data/carmichael-1e24-oracle.orc1
# make decode-111x
pwt2_decode data/carmichael-1e24-cell111x-pwt-dstar.pwt2 --emit-n work/c111x.n.raw
# make paths-111x
pwt2_decode data/carmichael-1e24-cell111x-pwt-dstar.pwt2 --emit-paths work/c111x.paths.bin --fields 14

The reproduce page explains the folders and the defaults.
